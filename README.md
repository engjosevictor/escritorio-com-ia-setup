# setup-escritorio

Skill do Claude Code.

## Instalação

Dentro da pasta do seu projeto:

```
git clone https://github.com/engjosevictor/escritorio-com-ia-setup.git .claude/skills/setup-escritorio
```

## Uso

No Claude Code:
```
/setup-escritorio
```

No Codex, na primeira vez (depois disso o script de ponte em `scripts/`, rodado automaticamente pelo próprio setup, mantém `.agents/skills` sincronizado com `.claude/skills`, então qualquer skill nova também passa a funcionar sozinha no Codex):
```
leia e siga o arquivo .claude/skills/setup-escritorio/SKILL.md
```
